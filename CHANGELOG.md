# Changelog

## 0.2.0 — experimental research toolkit

- Combined the Core and Toolkit source into one offline-installable distribution.
- Added descriptor-anchored POSIX file access, pre-read size caps, and fail-closed handling for unsupported filesystem APIs.
- Added bounded-read, symlink-swap, ancestor-swap, nonregular-file, concurrent-growth, and CLI redaction regressions.
- Added research-focused scope and explicit negative findings.
- Published as experimental research software under Apache License 2.0; research findings remain negative and limitations unchanged.
