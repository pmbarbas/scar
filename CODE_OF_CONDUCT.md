# Community expectations

Participation should be respectful, evidence-based, and safe for people from different backgrounds. Harassment, threats, doxxing, discriminatory conduct, and deliberate disclosure of sensitive evidence are not acceptable. Keep technical criticism focused on claims, methods, and code.

Repository maintainers are responsible for moderation. For conduct concerns, contact the repository owner through GitHub without posting private details publicly; for security vulnerabilities, follow [SECURITY.md](SECURITY.md). No response time or support service is promised.
